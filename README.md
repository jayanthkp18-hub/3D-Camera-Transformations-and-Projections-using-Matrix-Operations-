# 3D Camera Transformations and Projections using Matrix Operations

A mathematical and computational project that demonstrates how matrix operations are used in 3D computer graphics for camera transformations and projections.

The project explores transformations such as translation, rotation, and scaling, along with camera transformations and perspective projection to convert 3D coordinates into a 2D image plane.

## Objectives

- Understand 3D transformations using matrices.
- Implement camera transformations mathematically.
- Explore perspective projection from 3D to 2D.
- Visualize the effect of different transformations and camera parameters.
- Connect mathematical concepts with practical computer graphics applications.
